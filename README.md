# 🚀 Ezhilkumaran M - Personal Portfolio

Welcome to the repository of my personal portfolio website! This project showcases my skills, experience, and projects in a modern, interactive, and visually appealing way.

## 🛠️ Tools & Technologies Used

This portfolio was built using modern web development tools to ensure high performance and a great user experience:

- **React.js**: Core frontend library for building the user interface.
- **Vite**: Ultra-fast frontend build tool and development server.
- **Tailwind CSS (v4)**: Utility-first CSS framework for rapid and responsive styling.
- **Framer Motion**: Animation library used for smooth page transitions and interactive elements.
- **Lucide React & React Icons**: For clean and beautiful scalable vector icons.
- **React Scroll**: For smooth scrolling navigation between different sections.

## 📂 Project Structure

The project is structured in a clean and modular way:

- `src/components/`: Contains all the reusable UI sections (Hero, About, Projects, Skills, Contact, etc.).
- `src/constants.js`: The central data file where all my personal information, projects, and skills are stored. Updating this file automatically updates the website content.
- `public/`: Contains images, your downloadable resume, and other static assets.

## ⚙️ Development Workflow

If you'd like to run or modify this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ezhil-kumaran-27/My-Portfolio.git
   cd My-Portfolio/portfolio
   ```

2. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

4. **Building for Production:**
   ```bash
   npm run build
   ```
   This generates an optimized production build in the `dist` folder, ready for deployment to Vercel, Netlify, or GitHub Pages.

## ✨ Key Features

- **Dynamic Content**: Powered entirely by a central `constants.js` file, making content updates completely effortless without touching the UI code.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
- **Glassmorphism UI**: Uses a modern translucent design style with a custom premium color palette.
- **Interactive Animations**: Elements smoothly animate into view as you scroll down the page.
